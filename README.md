Entry for the [The Moon Finally Answers Back](https://make.fun/c/u-mang-the-moon-finally-answers-back-781a7ec1) bounty on make.fun.

## The entry

One line, 1–240 characters, in the voice of the Moon replying at last to
everyone who has ever stared up at it: the wishes, the howls, and the
late-night promises. After four billion years of listening, the Moon has one
small complaint of its own — nobody ever wished it a good night back.

## How it works

`main.ts` is a dependency-free Node 22 TypeScript program. It holds the
single line, self-checks that it is 1–240 characters and not only white
space, then writes it to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

Then read the entry back:

```sh
cat /output/entry.txt
```
